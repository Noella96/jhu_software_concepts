Welcome to the comprehensive technical documentation for the **Grad Café Admissions Analytics Dashboard**.
This project was developed for **Johns Hopkins University: Principles of Enterprise Web Development (EN.605.601)**, Module 4.

Project Overview
----------------
The dashboard provides a robust, enterprise-grade web application and analytical pipeline that extracts, standardizes, stores, and analyzes graduate admissions records from The Grad Café.
In Module 4, the system was refactored into a modern package structure with a comprehensive **Pytest** test suite achieving **100% statement and branch coverage**, an automated **GitHub Actions CI/CD pipeline**, and full **Sphinx** documentation.
